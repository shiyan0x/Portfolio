# Portfolio Website

A modern, interactive portfolio website showcasing my skills and projects as a web developer and student. Built with HTML, CSS, JavaScript, and Three.js to create an engaging 3D experience.

## 🚀 Features

- **Responsive Design**: Mobile-first approach ensuring optimal viewing on all devices
- **Interactive 3D Background**: Custom Three.js scene with animated elements
- **Smooth Navigation**: Single-page application with smooth scrolling between sections
- **Skills Showcase**: Visual representation of technical skills with progress bars
- **Project Gallery**: Display of key projects with descriptions and tech stacks
- **Contact Information**: Direct links to email, phone, and social media profiles
- **Modern UI/UX**: Clean, professional design with glitch effects and animations

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Responsive styling, animations, and gradients
- **JavaScript (ES6+)**: Interactive functionality and DOM manipulation
- **Three.js**: 3D graphics and WebGL animations
- **Font Awesome**: Icons for skills and social links

## 📋 Sections

1. **Home**: Hero section with introduction and profile image
2. **About**: Personal background and passion for web development
3. **Skills**: Technical competencies including:
   - HTML & CSS (90%)
   - JavaScript (85%)
   - Three.js (75%)
   - Responsive Design (88%)
   - Python (85%)
   - Problem Solving (92%)
4. **Projects**: Showcase of featured projects:
   - Music Player App
   - 3D Game Portfolio
   - Task Management System
5. **Contact**: Contact details and social media links

## 🏃‍♂️ Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection for external libraries (Three.js, Font Awesome)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/shiyan0x/Portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Portfolio
   ```
3. Open `index.html` in your web browser

That's it! The website will load with all interactive features.
